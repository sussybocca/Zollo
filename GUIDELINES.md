# Zollo Project Guidelines

- Keep Python package code in `zollo/`.
- User Python scripts go in `py/Zollo/backend/files/py/`.
- Node projects go in `node/Zollo/frontend/files/js/`.
- Use the CLI commands: `bundle`, `unhide`, `clean`.
- Avoid committing virtual environments (`.venv`) and build outputs (`.zollo_build`).
- Always update `pyproject.toml` version before publishing.
