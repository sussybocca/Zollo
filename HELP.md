# Zollo Help

## Commands

- `zollo --help` → Show all available commands.
- `zollo bundle` → Bundles Python and Node projects.
- `zollo unhide` → Unhide the `.zollo_build` folder.
- `zollo clean` → Remove previous build output.

## Troubleshooting

- **Python folder missing** → Ensure scripts exist in `py/Zollo/backend/files/py/`.
- **Node folder missing** → Ensure `package.json` exists in `node/Zollo/frontend/files/js/`.
- **npm not found** → Install Node.js and ensure `npm` is on PATH.
- **Build folder not found** → Run `zollo bundle` from the project root.
